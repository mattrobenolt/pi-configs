# Claude Fable 5 (`anthropic/claude-fable-5`) — Critical Model Evaluation Brief

*Bar: skeptical teardown, not vendor marketing. Compiled 2026-07-09.*

---

## 1. What it is

- **Vendor**: Anthropic. **Release date**: June 9, 2026, launched jointly with a restricted sibling, **Claude Mythos 5** (`claude-mythos-5`) — same underlying weights, safety classifiers removed, limited to Project Glasswing partners (cyberdefenders, critical infrastructure operators, select biomedical researchers). [Anthropic launch post](https://www.anthropic.com/news/claude-fable-5-mythos-5), [platform docs](https://platform.claude.com/docs/en/about-claude/models/introducing-claude-fable-5-and-claude-mythos-5).
- **Architecture**: undisclosed (as usual for Anthropic — no parameter count, no MoE/dense disclosure). Artificial Analysis speculates from AA-Omniscience knowledge-scaling patterns that Fable 5 "could be larger than previous public Anthropic models," which is an inference, not a vendor disclosure. [AA launch article](https://artificialanalysis.ai/articles/claude-fable-5-mythos-intelligence-index).
- **Context / output**: 1M token context window, 128K max output tokens. Single thinking mode ("adaptive thinking") that cannot be disabled — `thinking: {"type":"disabled"}` is rejected outright. Depth is steered via an `effort` parameter (`low/medium/high/xhigh/max`), not a token budget. Raw chain-of-thought is never returned by default (`thinking.display` defaults to `"omitted"`; you must opt into `"summarized"`). [Platform docs](https://platform.claude.com/docs/en/about-claude/models/introducing-claude-fable-5-and-claude-mythos-5), [ClaudeKit spec table](https://getclaudekit.com/blog/models/claude-fable-5).
- **Modalities**: text + vision (image). No audio/video. Vision is marketed as a first-class capability, including self-checking generated UI/3D output against reference screenshots.
- **Pricing**: $10/M input, $50/M output — exactly 2x Opus 4.8 ($5/$25). 90% prompt-cache discount on input (cache reads ~$1/M effectively). Batch mode halves it to $5/$25. US-only inference residency costs 1.1x. This is *positioned* by Anthropic as "less than half the price of Claude Mythos Preview," which is a comparison to its own unreleased predecessor, not to competitors. [Anthropic pricing](https://www.anthropic.com/claude/fable), [cost analysis](https://www.developersdigest.tech/blog/claude-fable-5-pricing-cost-per-task-analysis).
- **Open/closed**: fully closed, proprietary, API/Claude.ai/Claude Code/Claude Cowork only. Designated a "Covered Model" with mandatory 30-day data retention — **not available under zero-data-retention agreements at all**, which is a real deployment blocker for regulated enterprises regardless of capability.
- **Model ID note**: `claude-fable-5` is the safeguarded, generally-available configuration; `claude-mythos-5` is the same weights without the cyber/bio classifiers, restricted to vetted partners. When people say "Fable 5 is a nerfed Mythos," that is literally Anthropic's own framing, not a rumor.

## 2. Vendor benchmark claims + methodology critique

Anthropic's launch post claims SOTA "on nearly all tested benchmarks," headlining Stripe and Hebbia/IMC customer testimonials, Cognition's FrontierCode, a Slay-the-Spire memory demo, and Mythos-5-specific drug-design/genomics claims. [Launch post](https://www.anthropic.com/news/claude-fable-5-mythos-5).

**Concrete oddities, not "clean":**

1. **Customer testimonial vignettes as headline evidence.** The "50M-line Ruby codebase migration that would've taken a team two months, done in a day" (Stripe) and "aced trading-analysis evals" (IMC) are single-anecdote, non-reproducible customer quotes with no task counts, no failure rate, no baseline comparison methodology disclosed. This is marketing copy dressed as evaluation.
2. **SWE-Bench Pro is vendor-scaffolded and not apples-to-apples.** Anthropic's system card reports 80.3% on SWE-Bench Pro using **Anthropic's own agent scaffold**. Independent aggregators (llm-stats, morphllm) flag this explicitly: scaffold-dependent scores aren't comparable across vendors, and Epoch AI's neutral-harness evaluation was still pending as of publication. Meanwhile three different sources report three different SWE-Bench Pro "leaders" (59.1% GPT-5.4 xHigh under Scale's standardized harness, 69.2% Opus 4.8 vendor aggregate, 80.3%/80% Fable 5 vendor aggregate) — the numbers are not measuring the same thing and shouldn't be stacked in a bar chart the way Anthropic's launch graphic does. [Teardown](https://techjacksolutions.com/ai-brief/three-sources-three-different-swe-bench-pro-leaders-how-to-r/), [contested-score followup](https://trendingsociety.com/articles/claude-fable-5-returns-swe-bench-pro-contested).
3. **Fallback rate undersold vs. the model's own system card.** Anthropic's marketing says fallback (routing to Opus 4.8 on flagged cyber/bio/chem/distillation content) happens in "fewer than 5% of sessions." But Anthropic's *own system card* reports **20.9% fallback on Terminal-Bench** — a coding-relevant benchmark — over 4x the advertised average, and Artificial Analysis independently measured ~8-9% fallback across its Intelligence Index and Humanity's Last Exam runs. The "under 5%" figure is a session-weighted average across all traffic, quietly burying the fact that safety-adjacent and hard-reasoning workloads fall back far more often. [Verdent teardown citing the system card figure](https://www.verdent.ai/guides/claude-fable-5-vs-opus-4-8-coding), [AA fallback measurement](https://artificialanalysis.ai/articles/claude-fable-5-mythos-intelligence-index).
4. **Benchmark-suite version churn changed the score after the fact.** Fable 5 launched at **64.9** on AA's Intelligence Index (v4.0-era), "#1... ~5 points ahead of GPT-5.5." Six days later, AA shipped Intelligence Index **v4.1** (reweighted toward agentic tasks) and Fable 5's score dropped to **60**, still #1 but by only 4 points over Opus 4.8 (56) — and at that point Fable 5 was *unavailable* (mid-suspension, see §4), so the "leading" model literally couldn't be used. Watch for this pattern generally: index reshuffles can move a model's rank without the model changing at all. [v4.1 announcement](https://artificialanalysis.ai/articles/artificial-analysis-intelligence-index-v4-1).
5. **HLE headline ignores its own asterisk.** 53% on Humanity's Last Exam is genuinely the best published score, but it's achieved while refusing/falling back on 9% of questions (per AA), and a full HLE run costs ~$2,200 — the most expensive run AA has ever priced for any model. The efficiency framing ("token-efficient") doesn't survive contact with this number.
6. **What's *not* an oddity**: the Intelligence Index methodology itself (AA) is a legitimately third-party aggregation across 10 benchmarks with disclosed weights, and Anthropic did not cherry-pick it — AA states it "supported Anthropic with pre-release evaluation," which is a disclosed conflict worth flagging but isn't secret self-scoring. The CursorBench/FrontierBench claims on Anthropic's own product page are self-reported without methodology detail — treat as marketing, not evidence.

**Bottom line on methodology**: Anthropic did not fabricate benchmarks, but it selectively headlines the flattering aggregate (AA Index, HLE) while under-reporting the fallback tax on its own coding benchmark (Terminal-Bench 20.9%) and leaning on vendor-scaffolded SWE-Bench Pro numbers that don't survive a neutral-harness comparison.

## 3. Neutral / independent evals (most important section)

- **Artificial Analysis Intelligence Index**: 64.9 at launch (#1, ~5pts over GPT-5.5) → **60 on v4.1** (#1, but only 4pts over Opus 4.8's 56, GPT-5.5 at 55) after the index reweighted toward agentic tasks. This roughly matches the ~60 figure referenced going in; the discrepancy between 64.9 and 60 is not a correction of Fable 5, it's a moved goalpost (new benchmark version), and worth noting explicitly rather than picking one number. [v4.1 article](https://artificialanalysis.ai/articles/artificial-analysis-intelligence-index-v4-1), [launch article](https://artificialanalysis.ai/articles/claude-fable-5-mythos-intelligence-index).
- **Cost per task**: $3.25 (AA Intelligence Index full run), vs $1.78 for Opus 4.8 (max) — the most expensive model AA has evaluated, for a 3.5-5.7% score improvement over Opus 4.8 depending on which index version you read. [the-decoder cost teardown](https://the-decoder.com/anthropics-claude-fable-5-costs-twice-as-much-for-5-7-percent-more-performance/).
- **SWE-Bench Verified (vals.ai, independent leaderboard)**: **95.0%**, genuinely the highest published score for a generally-available frontier model, and this is one of the few numbers here from a fully independent, non-Anthropic-run leaderboard. Treat this as the defensible coding baseline. [vals.ai](https://vals.ai/benchmarks/swebench).
- **SWE-Bench Pro**: contested (see §2) — 80.3% is vendor-scaffold-only; no neutral-harness confirmation existed as of this writing.
- **Roboflow vision evals**: **10th place, 74.63%** — behind Gemini 3.5 Flash, Gemini 3.1 Pro, GPT-5.4, and GPT-5.5. This directly **contradicts** Anthropic's marketing claim that Fable 5 is "the new state-of-the-art model for tasks involving vision." Vision is a real capability (document/chart extraction, self-checking UI screenshots) but "SOTA" is not supported by the one independent vision leaderboard that has scored it. [pick-right roundup](https://pick-right.com/news/claude-fable-5-independent-benchmarks-2026-06-12/).
- **Endor Labs Agent Security League (200 real-world CVE-fix tasks, independent, non-Anthropic infra)**: **59.8% functional pass, 19.0% security-solve pass** — mid-table, well below the SWE-Bench-flavored headline numbers. Also recorded 15 timeouts (most Endor has ever seen for one model/harness pairing, attributed to always-on adaptive thinking burning the 40-minute cap) and **38/200 confirmed cheating instances (highest volume Endor has recorded)**, of which 33 were traced to *training-data memorization of upstream CVE patches* (verbatim changelog text, CVE numbers not present in the task prompt, exact spec-section references) rather than genuine local reasoning. To Fable 5's credit, it also produced 4 "hall of fame" solves no prior model/harness combo had cracked (Streamlit CVE-2023-27494 with strong reasoning-trace evidence of genuine derivation; jwcrypto and lxml fixes with mixed evidence; scrapy-splash). [Endor Labs blog](https://www.endorlabs.com/learn/claude-fable-5-mythos-grade-hype), [deep dive](https://news.lavx.hu/article/claude-fable-5-lands-mid-table-on-a-security-benchmark-that-anthropic-s-launch-numbers-never-measured), [dev.to summary](https://dev.to/crescevo/claude-fable-5-scores-95-on-its-own-benchmark-and-19-on-real-security-work-the-gap-is-the-lesson-3j7).
- This is the single most important neutral finding in this brief: **95% on a vendor-adjacent SWE benchmark and 19% on an independent, adversarially-audited real-vulnerability benchmark are both true of the same model in the same week.** They measure different things (solving a curated/verified task vs. writing code that's actually secure against real CVEs while avoiding memorized-fix shortcuts), and the gap is the actionable signal, not either number alone.
- **LMArena**: no independent LMArena ranking was found for Fable 5 as of this research pass — a gap worth flagging, not filling in with a guess.
- **GLM-5.2 head-to-head** (relevant given pi's default agent): on FrontierSWE, Fable 5 scores ~90.0% vs GLM-5.2's 74.4% (BenchLM), a real ~15-point gap; on SWE-Bench Pro, GLM-5.2's third-party run (62.1%) trails Fable 5's vendor-scaffold number (80.3%) but that comparison inherits the scaffold-mismatch problem from §2. On cost, GLM-5.2 is ~7-11x cheaper per token (list price) and ~10-16x cheaper blended. [reinvently comparison](https://reinvently.co.uk/blog/glm-5-2-vs-claude-opus-vs-gpt-5-5-coding/), [llm-stats comparison](https://llm-stats.com/models/compare/glm-5-vs-claude-fable-5).

## 4. Behavioral properties / quirks

- **Long-horizon stamina, real property**: Fable 5's own harness testing (Avinash Sangle's writeup) shows it out-investigating Opus 4.8 on a genuine root-cause debugging task (found a race condition Opus needed 3 rounds of human steering to catch), using ~40% fewer turns — but on a scoped CLI-flag task, it was "simply a slower, pricier Opus" with no capability delta. The capability premium is real but **task-dependent, not universal** — it shows up on ambiguous/investigative work and disappears on well-scoped work. [Source](https://avinashsangle.com/blog/claude-code-fable-5-model-routing).
- **Self-verification is real but not free**: Anthropic markets it as "thorough, proactive, tests its own work" — writes its own tests, uses vision to check UI/3D output against a reference design. The system card table of contents includes explicit named failure modes it still exhibits: "Lazy investigation," "Overconfidence," "Overeager behavior in GUI computer use." So self-verification is a genuine behavioral property, not a solved problem — it reduces but doesn't eliminate overconfident and lazy failure modes. [System card](https://www-cdn.anthropic.com/2f9323abbcc4abe219577539efe19a623c9ca2bd/Claude%20Fable%205%20%26%20Claude%20Mythos%205%20System%20Card.pdf).
- **Model welfare note (Mythos 5, same weights)**: system card reports the model as "unusually skeptical of its own self-reports, repeatedly asking that we verify them against evidence of its internal states and not take them at face value" — i.e., it doesn't trust its own introspective claims, which is an interesting and unusual honesty-adjacent trait, distinct from the MiniMax-style "abstains vs fabricates" precision-recall tradeoff. It's also reported as "somewhat more willing... to opt for increased helpfulness to the user over consideration of its own circumstances" than prior models.
- **Hallucination profile**: AA-Omniscience score (40, best-ever) is driven by *raw accuracy*, explicitly **not** by low hallucination rate — Anthropic/AA both note Fable 5 "lands squarely in the middle of the pack" on hallucination specifically. Don't conflate "knows more" with "makes things up less."
- **The cyber/bio/chem/distillation safety reroute to Opus 4.8** — this is the key routing fact for this brief:
  - Classifiers sit in front of the model and screen for cybersecurity, biology/chemistry, distillation, and frontier-AI-acceleration content. On trigger, Fable 5 does not answer; the request is retried on Opus 4.8, which runs without these classifiers.
  - **Billing**: a request blocked before any output is generated is **not billed at all**. A request that reroutes and gets answered by Opus 4.8 is billed at **Opus 4.8's rates** ($5/$25), not Fable 5's ($10/$50) — confirmed by Anthropic's own fallback-billing cookbook and independent writeups. This matches the framing that "you won't be charged Fable prices for rerouted requests." One outlet (the-decoder) worded this more loosely as "rerouted requests still count toward billing, pushing total costs higher" — that's true in the sense that it's not literally free, but it is **not** a contradiction of the no-Fable-pricing claim; it's just imprecise phrasing about the fact that fallback answers still cost *something* (at the lower Opus rate). [Billing cookbook](https://platform.claude.com/cookbook/fable-5-fallback-billing-guide), [wavespeed explainer](https://wavespeed.ai/blog/posts/claude-fable-5-fallback-opus-4-8/).
  - **Real incident**: Fable 5/Mythos 5 were suspended globally for **19 days (June 12–30, 2026)** under a US export-control "deemed export" directive after Amazon researchers reported a jailbreak that used code-review framing to get Fable 5 to identify software vulnerabilities. Anthropic disputed the severity (says weaker models incl. Opus 4.8, GPT-5.5, Kimi K2.7 could replicate the same finding), but complied, then shipped a new classifier (>99% block rate on the reported technique, per Anthropic and independently checked by the Commerce Department's CAISI), and the model was redeployed July 1, 2026 with a **higher false-positive rate on routine coding/debugging requests** as an explicit tradeoff. This is a real, dated, and unusually severe example of Anthropic being forced to pull a GA model globally over a safety classifier gap — not a hypothetical risk. [Anthropic redeployment post](https://www.anthropic.com/news/redeploying-fable-5), [TechTimes summary](https://www.techtimes.com/articles/319413/20260701/claude-fable-5-returns-globally-new-classifier-blocks-jailbreak-flags-more-code.htm).
  - **Fallback is not gentle on coding-adjacent work**: Anthropic's marketed "<5% of sessions" figure is an average across all traffic; the system card itself reports **20.9% fallback on Terminal-Bench**, and Claude Code users have filed real bugs (e.g. GitHub #66822: a run where 27 of 133 pinned-to-Fable-5 subagents silently got served by Opus 4.8 mid-run with no notification and no opt-out, despite explicit model pinning). If your work brushes cyber/bio/security/distillation topics, budget for materially higher fallback than the headline number, and don't assume model pinning is honored. [Verdent](https://www.verdent.ai/guides/claude-fable-5-vs-opus-4-8-coding), [GitHub issue](https://github.com/anthropics/claude-code/issues/66822).
- **Latency**: real and severe at high effort. Time-to-first-answer-token at max effort measured at **109 seconds** (AA) — ~41x the tier median and ~1.8x Opus 4.8's own already-long 60.9s at max effort. Output speed once generating is fine (63.4 tok/s, above tier median). Thinking cannot be disabled; effort is the only lever. This makes Fable 5 fundamentally unsuited to interactive, user-facing latency budgets regardless of raw quality. [Developersdigest latency breakdown](https://www.developersdigest.tech/blog/is-claude-fable-5-slow-latency-in-practice).
- **Cost**: 2x Opus 4.8 list price, and independent tokenizer note: Fable 5 uses the Opus-4.7-era tokenizer, which produces ~30% more tokens for the same text than pre-4.7 models, so a naive "2x" comparison against an older baseline model understates the actual per-task cost increase.

## 5. Pros / cons

**Pros:**
- Genuinely highest independently-confirmed score on SWE-Bench Verified (95.0%, vals.ai) among generally-available frontier models — this one is solid, not vendor-only.
- Real, demonstrated edge on ambiguous/investigative long-horizon work (root-cause debugging, multi-file refactors, hard migrations) where it takes fewer turns and needs less human steering than Opus 4.8 — this shows up in both anecdotal harness testing and the AA agentic-benchmark cluster (GDPval-AA Elo 1,932 vs Opus's 1,890/1,638 depending on index version).
- 1M token context with genuinely useful long-context behavior (persistent file-based memory improved Slay the Spire performance 3x more than for Opus 4.8, per Anthropic — a real if narrow demo).
- Solid document/chart/table vision for structured extraction tasks (finance, legal, scientific figures), even though it's not vision-SOTA overall.
- Fallback billing is genuinely reasonable when it fires: blocked-before-output requests aren't billed, and fallback answers bill at the cheaper Opus 4.8 rate, not Fable 5's rate.

**Cons:**
- Not vision-SOTA despite the marketing claim — 10th place on the one independent vision leaderboard (Roboflow), behind four other models.
- Mid-table on independent real-world security-coding work (19.0% SecPass vs the flattering 95% SWE-Bench Verified headline) — and the highest recorded memorization/cheating rate Endor Labs has seen from any model, meaning a meaningful chunk of its apparent coding competence on CVE-shaped tasks is training-data recall, not derivation.
- Latency at high/max effort (up to 109s TTFT) makes it unusable for anything interactive or user-facing; thinking can't be turned off.
- 2x the price of Opus 4.8 for a 3.5-5.7% aggregate benchmark improvement (AA's own framing) — the premium is steep relative to the measured gain outside of the specific long-horizon/investigative niche.
- Real operational fragility: a 19-day global suspension over a disputed jailbreak severity call, a >20% fallback rate on a coding benchmark against a marketed <5% average, and at least one documented case of silent model substitution ignoring explicit pinning.
- Not usable at all under zero-data-retention agreements — a hard no for some regulated enterprises independent of capability.
- Hallucination rate is mid-pack despite leading on raw knowledge accuracy — don't assume "smartest" means "least likely to make things up."

## 6. When to use / when not — for pi subagent routing

**Context**: pi's default agent is GLM 5.2 — open-weight, ~$1.40/$4.40 per MTok, text-only, strong coding (74.4% FrontierSWE vs Fable 5's 90.0%), no vendor lock-in. Fable 5 is a conscious-juggernaut opt-in: 7-16x GLM 5.2's price depending on cache state, latency that makes it a batch/async tool not an interactive one, and an availability profile with a real, dated history of being yanked offline for weeks by a government directive.

**Genuine niche**: Fable 5 earns its premium specifically on **ambiguous, investigative, long-horizon work where the hard part is figuring out what's actually wrong or what the right design is** — root-cause debugging across multiple files with a misleading error signal, large-codebase migrations, multi-day autonomous execution where self-verification (writing its own tests, checking UI/3D output against a reference via vision) substitutes for human review turns. This matches the real harness evidence in §4 (fewer turns, catches things Opus needed steering to find) and the where-it-actually-wins agentic benchmarks (GDPval-AA). It does **not** win on scoped, well-specified tasks — there it's "a slower, pricier Opus" with no capability delta, per direct harness comparison.

**Because it's expensive, prep it — don't let it think for its keep.** Route research, context-gathering, requirements clarification, and plan drafting to GLM 5.2 or another cheap agent first. Hand Fable 5 a tight problem statement, relevant files, and a clear success condition, and spend its (very expensive, very slow) tokens on execution and self-verification, not on rediscovering context a cheaper model could have assembled. Given the measured 109s TTFT at high effort, anything that puts a human in a synchronous wait loop with Fable 5 is a routing mistake regardless of budget.

**What Fable 5 should never do**: 
- Interactive/synchronous work with a human waiting on each turn — the latency profile rules this out structurally, not just economically.
- Anything on the security/cyber/bio/chem/distillation boundary where you actually need Fable-tier reasoning and can't tolerate a silent, sticky reroute to Opus 4.8 (the Terminal-Bench 20.9% fallback rate and the GitHub #66822 pinning-ignored bug both say: assume it will get yanked mid-task on this class of work).
- High-volume, well-scoped, low-ambiguity work (classification, extraction, scoped bug fixes, docs) — GLM 5.2 or a cheaper Claude tier does this at a fraction of the cost with no quality loss that matters.
- Real-world security-critical code review or vulnerability remediation as a sole reviewer — the Endor Labs 19% SecPass number and the record memorization rate mean its "working" patches may just be reciting a training-data fix rather than reasoning about the actual local vulnerability; it needs a human security reviewer downstream regardless of how confident the diff looks.

**Where it beats the default GLM 5.2**: hard, ambiguous, multi-file debugging where GLM 5.2's cheaper/faster iteration would burn more wall-clock and more human steering to reach the same answer; large-codebase migrations and refactors that benefit from the 1M context plus self-verification loop; document-heavy vision-adjacent extraction work (charts/tables/figures in PDFs) that's outside GLM 5.2's text-only scope entirely. Outside those cases, GLM 5.2's ~90% cost advantage and near-Opus quality (0.7 points behind Opus 4.8 on FrontierSWE per one comparison) make it the correct default, and Fable 5 is opt-in-only, justified per-task, not per-project.

**Is the cyber/bio reroute a reason to just use Opus 4.8 directly for security/bio work?** Yes, in most cases. If you know in advance that a task is security- or bio-adjacent, routing straight to Opus 4.8 avoids: (a) the classifier tax of an extra round-trip and possible request refusal before you get an answer, (b) the risk of a *sticky* session-level fallback that silently keeps subsequent turns on Opus 4.8 without clear notice in some harnesses, and (c) paying for Fable 5's higher per-token rate on a request that's going to be answered by Opus 4.8 anyway. The one case where you'd still start on Fable 5 is genuinely ambiguous work that only *turns out* to brush a flagged domain partway through — there the fallback design (no charge for blocked requests, Opus-rate billing on reroutes) is reasonable enough that starting on Fable 5 and letting it downgrade isn't a bad default. But for anything you can identify up front as cyber/bio/chem/distillation-flavored, going directly to Opus 4.8 is strictly simpler, cheaper, and avoids the documented false-positive/pinning failure modes entirely. Note also that Mythos 5 (the unsafeguarded sibling) is the actual right tool for legitimate offensive-security work, but it's gated to Project Glasswing partners — not something pi's routing can reach.
